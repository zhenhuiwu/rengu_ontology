# 事件规则与真实告警（2026-10-27）

## 公开入口与事务

`app.contracts.rules.dispatch_event_rule(session, user, *, rule_code: str, event_id: str) -> dict`。
供事件投递执行器的显式 `rule_code` 路由调用；执行身份来自部署路由，不来自载荷。
函数不提交事务、不发送通知、不执行业务动作；内部 savepoint 将真实命中、告警、创建日志一起保存或回滚。
返回 `status=alert_created|deduped|not_matched`、`ruleId/ruleVersion` 和存在时的 `hitId/alertId`。
开启自动暂存但映射不可执行时，返回 `actionStatus=unavailable` 与明确 `actionReason`，不能显示已暂存或已执行。

`app.contracts.rules.lifecycle_transition_pairs(snapshot, *, object_kind: str, version: int) -> frozenset[tuple[str, str]]`
提供同一严格版本状态机读取核心，供规则和动作条件检查复用；只判断明确状态对属于迁移集合，调用方仍负责真实对象/API、身份权限、当前状态输入及绑定发布版，不代替 guard/effect 执行。

执行前重新读取真实用户、事件/规则/告警管理权限和对象行权限。只接受新入站、非 seed、非测试、保留原始 payload、接收时间、定义快照及发布版本的事件。
拒绝入站去重记录，拒绝无版本/旧快照补输入。事件定义须与绑定整版快照一致；入站后发布版改变时明确停止，不借当前新定义处理旧事件。
规则须仍有效、版本相同，条件/触发/输出/去重/冷却/自动暂存字段与绑定快照一致。

先取同发布流程的咨询锁，再锁事件/规则，稳定 `RH-<摘要>` 唯一编号绑定事件与规则；重入只返回既有命中，不增加告警。
跨事件冷却按真实非 seed 命中计算，不把旧示例历史变成执行基线。当前发布咨询锁串行保护本地规则写入，吞吐增大时再改共享发布锁。

## 已支持与明确边界

- 共享有限事件表达式读取已声明的原始字段，支持现有解释器的有限标量运算/比较；过滤复用真实事件过滤器。
- 支持 `(event.<原状态>, event.<新状态>) NOT IN lifecycle("对象API", 明确版本).transitions`（以及 `IN`）：对象 API 必须与事件定义绑定对象一致，生命周期版本必须在绑定发布快照中完整存在，状态与迁移引用必须完整。该条件只判断明确状态对属于迁移集合，不推测历史对象状态，也不自动执行生命周期迁移。
- 现存 `SM-ORD` 可在上述真实输入与同版本状态机齐备时生成告警。`R-012/R-019` 等跨对象/指标条件、`prev/wow` 和缺少指标时序基线的表达式仍明确不可执行。
- 只为 `output=告警` 保存 `Alert + RuleHit + AlertLog`。通知规则没有真实通道时拒绝，不能改成告警或伪记已通知。
- 去重键仅支持明确事件 ID、规则编号、事件绑定对象标识，以及唯一对应已声明字段 API/显示名的标量值。不从摘要、示例、日期说明或自然语言猜字段。冷却支持“不重复”或正整数秒/分钟/小时/天；未知格式拒绝。
- 自然语言 `then`、自动暂存中的计算说明/“上一个合法状态”等没有可执行映射，保持明确不可执行；本入口不创建或执行动作。显式动作事件路由仍由现有公开动作暂存入口处理。

## 只读预览与数据

规则回放复用 `EventExpression`，包含同一显式版本生命周期条件；回放按当前所选规则与当前发布状态机重算，仍不声称还原历史状态。
真实载荷缺失的存量记录继续显示无法求值，不补造载荷、不造新事件或业务告警来验证。
命中列表按真实命中时间倒序、服务端分页，默认每页10条。列表和详情在 SQL 中按真实受控对象身份与行权限筛选；缺映射或对象编号歧义时拒绝，详情不可见返回404。周命中、详情命中和待确认动作数量沿用同一可见范围，分页前计数。告警/命中仍通过原有页面查看。
对象行为页的命中分页、规则聚合和相关动作计数使用同一权限过滤。`recent_rule_hits` 要求显式身份；公开完整/告警目录及其实际调用者传入当前用户，后台worker的轻量目录不读取规则命中统计。
本组没有新增表、迁移、业务记录回填、示例修改或发布/推送。
