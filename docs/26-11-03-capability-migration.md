# 通用能力增量迁移与接续验收

本轮在保留 `rengu_ontology` 现有数据的前提下，扩展指标、函数、源通道和治理。不要导入其他机器的数据库覆盖已有定义或业务记录。

## 升级已有部署

1. 停止旧 API 与同步、事件、动作 worker，按部署既有方式备份平台数据库和服务端 `.env`。源业务库保持原样。
2. 更新代码与后端依赖（`cd backend`，`uv sync`）。MySQL binlog 使用 `mysql-replication`，不能只替换 Python 源文件而保留旧依赖。
3. 检查配置指向该部署原来的平台库，执行 `uv run alembic upgrade admin_0053_governance_policy`。
4. 按原启动方式启动 API，确认 `/readyz` 返回正常，再恢复各 worker。不要以迁移降级或清库解决版本问题。

`0052` 为已有只读绑定新增可空的视图唯一键声明，新增提交后行事实及独立写回授权表；`0053` 新增按本体隔离的治理策略表、扩大关系权限路径长度，并为动作记录新增可空用途字段。旧记录不改写；没有配置治理策略的本体保持原授权行为。迁移不可自动降级，以免删除事实证据或治理决策。

本机已执行上述 0052、0053 增量，未进行迁移升降级测试。其他电脑仍须执行自己的升级。

## 指标

引用已发布指标时固定版本：`METRIC('api_name','v1')`。跨对象指标先分别按原口径聚合，再组合结果，避免明细关联造成重复累计。公式编辑器可选择真实指标及窗口插入，不需要填写 JSON。

支持 `PREV`、`WOW`、`DELTA`、`PCT_CHANGE`、`MOVING_AVG`、`MOVING_SUM`、`RUNNING_SUM`；窗口按日历日、周、月计算，缺失值保持为空，只有显式 `COALESCE` 才补值。`GEO_DISTANCE` 对指标值中的两个经纬度点计算球面距离，单位为千米。普通单对象公式增加条件聚合 `SUM(CASE WHEN ... THEN ... ELSE ... END)`、去重计数和空值处理/取整。

组合层不接受另写时间字段或默认过滤：这些条件必须在被引用口径维护。引用版本变化、循环依赖、未获授权或无法确定的分组条件会明确拒绝。一次最多 8 项查询、32 次依赖求值、8 层依赖，时间查询最多 93 天；历史窗口内部有界读取。当前实现不包含任意跨对象明细 JOIN、任意 GIS/空间拓扑运算。

## 函数与数据库通道

受控远程函数部署合同见 [远程函数](26-11-03-remote-functions.md)。目标、网络、凭据只放服务器；函数保存固定修订、schema 与绑定摘要，测试、机器调用、动作和规则复用同一执行内核。第三方库、算法或模型运行在独立服务，不在 API 进程解除 AST 限制。

MySQL CDC、视图唯一键、数据库动作写回及源端回执 DDL 见 [源通道接续验收](26-11-03-source-channel-verification.md)。写回必须使用独立授权的写账号；提交结果未知时只对账，不再次发送。导出数据库的脱敏流程会清除该写账号的加密密码，目标电脑须重新配置自己的凭据。

## 增量链与发布实证

组合指标最初被正式发布的旧公式检查误拒，现保存检查与整本体发布复用同一元数据校验入口。完整本体已正式发布 `v2026.11.12`，其中事件 `FixtureScoreChanged v2` 明确订阅 `R-001`。

`ACT-20261103-0004` 在智能助手中将对象3评分更新为45，得到源事务成功回执；MySQL CDC产生 `CDC-3726b4cf84ce27679add1619e5af0367d4a7eae2e3cc454724a4be7770c7`。该事件实际投递成功1、失败/未知0，生成告警；规则命中页记录 `Score：45 · 函数 FN-001 v1.0.0 result：90`，条件为返回字段大于50。此次单订阅投递约6092毫秒，仅启用本体8该合成事件的限定worker，没有消费其他本体积压。

事件版本变化后CDC正确暂停并保留原游标。映射弹窗已明确旧固定版本失效，提供显式采用当前版本、复核兼容字段并保存的入口；不是自动替换版本或重建基线。

## 保留的异常证据

- `ACT-20261103-0001` 是旧异常处理留下的未知结果。原幂等回执只读查询返回未找到，仍保留未知；未重复发送，也未伪造人工成功或未执行结论。
- `ACT-20261103-0002` 明确在回执读取阶段遭权限拒绝，源事务未提交。已修正不可变回执不需要的行锁，目标业务行仍加锁；回执唯一键冲突只查询原hash/run结果，不再次UPDATE。新0003、0004成功不覆盖这两笔历史证据。
- 上述为独立合成MySQL的实际验收，不是正式第三方系统、DM独立写账号或生产流量验收。多跳关系、窗口边界和高精度小数等已有窄内存检查，未把离线断言称为全场景现场验收。

治理反例也已现场完成：取消明文授权后，问数聚合明确返回 `GOVERNANCE_DENIED`，没有返回评分或总和。验收结束恢复合成本体原无资源策略的基线（策略版本4），保留分类/用途词表及所有者授权候选；未改其他本体的策略。开启正式治理前仍需管理员补齐真实事件、远程函数和视图等无法自动证明的来源依赖，后台投递须配置明确用途。

本轮未运行后台全量测试、pytest、集成测试或迁移测试。首屏性能问题及逐接口实测见 [首屏性能记录](26-11-03-first-screen-performance.md)。
