# 事件类型与动作类型详情区溢出修复

## 根因

应用外壳已通过固定视口高度、弹性布局和 `min-height: 0` 将剩余高度传给页面与详情面板。事件类型的 `.et-body`、动作类型的 `.at-body` 也允许收缩，但概览内容没有承接内部滚动；自然高度较大的元信息、订阅方、最近事件或规则与提交条件会越过白色面板，进一步造成文档滚动。

两页侧栏目录同样只有 `flex: 1; min-height: 0`，没有目录内部滚动。事件类型的订阅方、版本历史以及动作类型的提交条件、版本历史直接放表格，也没有承接高度约束的滚动容器。动作类型的写回与副作用复用概览布局，属于相同缺陷。

## 修改

- 两页目录列表设置 `overflow: auto`，目录独立滚动，底部分页留在面板中。
- 概览以及动作类型的写回与副作用由 `.et-ov` / `.at-ov` 承接唯一的主内容滚动；新增自然高度的双列内容层（`flex: none; min-height: 100%`），保留左右布局、现有间距及统计侧栏，避免内容为适配高度而相互挤压。
- 原来缺少滚动容器的表格使用已有 `.paged-scroll`。载荷字段、动作参数、近期事件、执行记录和投递异常沿用原来的内部表格滚动，工具栏与分页保持可见。
- 未添加 `overflow: hidden`，未修改公共布局、后端、mock 数据、API、编辑器或业务逻辑。

## 验证

- `npm run typecheck`（`vue-tsc --noEmit`）：事件类型与动作类型修复后均通过，退出码 0。
- `git diff --check`：两个页面均通过，退出码 0。
- 事件类型概览，1920 × 1080：文档无外层滚动，`.et-ov` 为 `overflow: auto`，`clientHeight/scrollHeight = 830/830`，嵌套主内容滚动区数量为 0；最后事件 `EV…67` 位于面板内。
- 事件类型概览，1920 × 900：通过原生滚动实际到达 `scrollTop = 131.33`（可视高度 650，总高度 781）；最后事件 `EV…67` 的纵向边界为 `846.67..868.67`，小于面板底部 `887.33`，确认末行真实可达。
- 事件类型概览，2560 × 1440：`outerScroll = false`，无文档外层滚动。
- 动作类型概览，1920 × 1080：主内容区为 `overflow: auto`，`clientHeight/scrollHeight = 830/830`，嵌套主内容滚动区数量为 0。
- 动作类型写回与副作用，1920 × 900：通过原生滚动实际到达 `scrollTop = 1.33`（可视高度 650，总高度 651）。2560 × 1440：`outerScroll = false`。
