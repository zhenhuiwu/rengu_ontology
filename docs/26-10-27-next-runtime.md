# 动态规则与动作运行后续审计（2026-10-27）

基线 `59acc70`。本轮仅修已确认、无需新增业务决策的自动建议缺陷；主库只读，不改规则种子、指标定义、来源绑定或生产授权。

## 本轮已修复

1. 自动评估扫描候选后，原处理事务只按 ID 取告警，不再检查其是否已关闭、过期或已有人工决策。现处理前复用告警行锁 `FOR UPDATE SKIP LOCKED`，重新检查非种子、待处理/处理中、近24小时且不在未来、没有现成决策；忙碌行留待后续处理。失败记录事务同样重新核查，避免过时候选或中途已有人工决策后再追加错误记录。
2. 人工 `DecisionService.evaluate` 复用 `AlertService.get(lock=True)`，与自动评估和原告警处理共用同一条告警行锁。人工主动重新评估仍可产生新决策，不套自动“只评一次”门禁。
3. 原错误路径把 `repr(exc)` 或原业务异常消息直接持久化到 `decision_log.output.error`，并打印完整异常；驱动异常可能含 SQL/参数。现只保存通用提示及受控错误代码，日志只记告警 ID 和异常类型。异常不再携带原始 SQL、参数或消息进入记录和日志；失败仍是失败，不标成已执行或已成功。

精确产品路径：`backend/app/modules/dynamic/auto_decision.py`（候选/加锁/失败记录）、`backend/app/modules/dynamic/decisions.py`（人工评估沿既有告警权限获取行锁）。没有修改 `integration/execution.py`，确认人授权修复归管理/集成组。
