# 导入对象编辑与概览刷新修复（2026-10-31）

真实 GUI 联调对象：工作空间 15 的 `LiveFixture`，由达梦导入，保留 10 个既有属性，包括 `MixedCaseValue`、`ChangedAt`、`__mirror_row_id`、`__mirror_ontology_id`。本次修复只涉及两个 Vue 文件；没有改动后端、数据源授权或镜像配置。

## 1. 既有导入属性阻止保存定义

- **实测缺陷**：编辑定义时，既有属性 API 为只读，但校验仍要求全部属性 API 以小写字母开头。导入的大写及 `__` 字段导致保存按钮禁用，连仅修改对象说明也不能保存。
- **修复**：`frontend/src/pages/ontology/parts/DefinitionEditor.vue` 用 `WeakMap` 记录加载行及其原始 API。只有后端原有属性、仍为同一加载行且 API 与原值完全一致时，才允许保留原命名。新增属性和新建定义继续遵守原命名约束，重复 API 仍拒绝；没有通过重命名源字段绕过问题。
- **展示清理**：删除过期的“此处只保存定义草稿”横幅，并将移除确认提示改为保存后立即生效，未改变发布或保存行为。
- **真实 GUI 结果**：root 保留原有大写与 `__` 只读属性，仅修改说明，保存成功，工作版本到 `v5`。镜像代理只读核对确认数据库说明已变、对象版本已推进，镜像签名不变且完整性仍为 `full`，未触发重新同步。

## 2. 保存后当前对象概览描述不刷新

- **实测缺陷**：上述说明已保存，但同一对象的概览“描述”仍显示保存前的空值。
- **根因**：详情 DTO 的 `meta.desc` 到表单及概览的映射正确；概览详情监听对象选择与 `staticContextKey()`，而该上下文键不包含工作版本。保存推进 `app.ontologyVersion` 时，当前对象未切换，详情读取未重新执行。
- **修复**：`frontend/src/pages/ontology/ObjectTypesBody.vue` 的详情监听增加 `app.ontologyVersion` 依赖，工作版本推进后重新读取当前对象完整详情。
- **真实 GUI 结果**：root 再次仅修改 `LiveFixture` 说明并保存到 `v6`，没有切换对象、没有刷新页面，新说明立即出现在概览，完整文本精确匹配计数为 `1`。
