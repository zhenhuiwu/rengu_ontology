# 规则真实只读推演与回放（2026-10-27）

入口：构建 → 规则与自动化 → 回放试跑。定时规则默认“当前数据推演”，事件规则默认“历史事件回放”。当前/已保存草稿沿用原版本选择；服务端结果每页默认10条。

`POST /api/ontology/v1/rules/{id}:replay` 新增 `mode: snapshot|events`、`page`、`size`、可选 `anchor`，保留 `range: 7d|30d` 和 `version: current|draft`。仅规则 manage 身份可运行；历史版本和权限预览继续由原只读守卫拒绝。草稿必须有真实未发布变更单并通过变更单权限检查。

- 当前数据推演：读取已发布对象的受控表、真实属性 backing_column 与当前账号行权限。复用共享有限条件解释器；支持属性比较/有限算术及 `hours_since`、`minutes_since`，时间取数据库带时区值和服务器当前时间。API 属性的 camelCase 仅对应同名 snake_case 元数据。R-015、R-010、R-023 可从真实订单数据计算。
- 已保存阈值修改：只有原条件和表达式标量逐项唯一对应、运算符及单位未改变时才替换阈值；无法对应明确422。未保存的前端输入不参与计算。
- 历史事件回放：只重算订阅事件的保留原始 payload 和声明字段，执行可解释的事件筛选；按当前对象行权限裁剪，不能唯一定位对象的事件不读取，测试事件排除。没有原始载荷、缺字段、坏数据均计为“无法求值”，不从摘要或示例补造输入。
- 指标版本调用、`prev`、`wow`、跨对象函数、历史对象状态/生命周期上下文没有可执行基线时明确422。定时规则没有历史对象快照，历史事件模式明确拒绝；事件规则在缺载荷的当前模式同样拒绝。
- 不生成告警、通知、事件、动作、命中记录或持久推演结果；不执行调度。不声称历史还原，不估算新增/减少/冷却去重，兼容字段 `actual/added/removed/deduped` 返回 null。返回真实可见样本、求值、满足、未知和事件筛选排除数量；零样本不作为规则有效的证据。单次超过10000条明确拒绝，不返回冒充完整的部分结果。
- 翻页仍请求后台，传回首轮服务端签名 anchor；固定计算时间并绑定账号、对象行权限、规则定义与模式/范围，10分钟过期。每页重新读取当前DB，输入摘要变化时409要求重跑，避免混合分页；不缓存整批业务数据或假称数据快照。签名优先从受保护的 `RENGU_RULE_REPLAY_SIGNING_KEY` 按规则域隔离派生，兼容已显式配置的数据源密钥，热重载/同配置多worker保持有效；换签名密钥使旧anchor失效，缺稳定配置明确503，不用公开默认密钥。本地专用签名密钥仅在 ignored `backend/.env` 缺该配置时生成，未修改数据源加密密钥；新增环境配置后需重启后端。行值使用属性显示名，计算时长最多两位小数；详细范围说明放在计算时间旁提示中。
