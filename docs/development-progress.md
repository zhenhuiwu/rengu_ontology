## 外部配置与待定事项

- 开发数据库是 `localhost:5433/rengu_ontology`；`auto_ontology` 属于另一套系统，本轮不写入。
- 凭据只保留在被 Git 忽略的本地配置；测试使用独立的 `rengu_agent_*_test` 或用例自建临时库。
- 缺少大模型密钥和问数只读账号：真实问答质量评测尚不能执行，不伪造模型回答。
- 评测“同时只允许一个运行中”、审批界面、指标口径争议和额外数据库驱动仍需产品/外部条件，不自行扩大范围。
- 后台任务仍使用进程内调度；本轮恢复中断状态并提示重跑，持久队列与每日调度另列，不能宣称已实现自动续跑。
- dry-run 缺条件求值器/对象上下文，simulate 缺隔离测试目的地/确认机制且落库合同矛盾；见 palantir 交接 §7。真后台模式将禁用原只弹成功的入口，不伪造通过或投递。
- 审计导出 ready 表示固定成员可下载，文件在下载时生成；不包含后台文件生成队列。服务端按批读取，浏览器 Blob 仍会占完整文件内存，成员清理策略另列。
- 原系统鉴权仍是 dev/test 演示身份，`require_func` 及普通业务 `row_filter` 保留一期桩行为，prod 未接登录会直接 401；本轮候选范围校验、导出创建者校验不代表已完成生产鉴权。
- 旧历史快照从未保存的人工显示标记无法还原，使用初始定义默认值；权限范围目前只开放可执行的 string/enum 属性。
- 已验证前端代理、页面模块编译及主要真实接口；当前 CUA 没有可用浏览器，未完成 DOM、画面和控制台检查。
