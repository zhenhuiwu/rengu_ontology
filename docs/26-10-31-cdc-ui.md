# CDC 前端操作与验证记录（2026-10-31）

## 操作步骤

1. 在“数据连接”编辑达梦数据源，将同步方式保存为“实时（CDC）”。保存只设置意图，不会给任何源表安装触发器或自动启用对象。
2. 打开“同步计划”，找到已配置读取授权的目标对象，选择“配置 CDC”。对象标识与操作均由现有绑定提供，无需填写 JSON。
3. 选择“检测 CDC 能力”。检测是显式的源端只读检查；能力可用不代表安装权限已经验证。
4. 选择“预览安装 SQL”，核对源表、专用捕获资源及 SQL。可以下载适用于 disql 的参考 SQL（完整触发器体保留，末尾独立 `/`）；预览不会执行源端 DDL。独立显示安装后事务栅栏 `bootstrapFenceSql`：NOWAIT 请求源表排他锁，成功后 COMMIT 立即释放，不在锁内做初始扫描。栅栏失败须处理未结束事务或 LOCK 权限后重试同一计划。DBA 手工应用 SQL 后，仍须经界面确认安装，由 API 验证资源并记录栅栏。
5. 选择“确认安装源捕获”，在普通确认对话中再次核对目标源表。只有此动作会安装本对象的事务触发器捕获资源。
6. 选择“启用 CDC”。状态依次反映初始同步、追赶增量和持续同步；实际状态以服务返回为准。全量任务运行时不能启用或恢复同一对象 CDC。
7. “暂停消费”保留源端触发器及已捕获变更；源端继续累积变更。“恢复消费”继续处理。暂停消费不是卸载捕获资源。

## 状态与边界

- 捕获机制明确标为“事务触发器 CDC”，不会将原有定时全量称为 CDC，也不会将其称为原生日志 CDC。
- 对象摘要显示阶段、待处理数量、最近应用及采集健康；详情显示心跳、观测时间、捕获代次、待确认应用和 SQL。
- 待处理数量或时长未知时显示“未测得”；时间空值显示“—”。最近源触发时间不是事务提交时间，界面不显示提交位点或提交延迟。最早待处理时长表示源触发记录积压时长。
- 采集健康来自本地状态接口的消费者心跳判断，不能据此承诺固定端到端延迟。状态自动刷新不触发源端全量扫描。
- 缺少 0049 时显示升级恢复路径，不要求清库或解除绑定。权限、断线及源结构错误显示服务返回消息及恢复动作。
- 读取授权变更与解除绑定在 CDC 消费启用时禁用，需先暂停。绑定或源结构变化后，须重新核对、预览并安装捕获，再明确重新初始化；界面不会静默安装或恢复。
- 活动 CDC 与同对象人工全量互斥；初始同步期间原全量取消按钮禁用并提示先暂停 CDC，暂停后若基线已取消则依据 restartRequired/recoveryAction 展示重新初始化、禁用恢复；现有全量同步、取消、断点恢复和记录保留。CDC 初始同步记录明确标注来源。
- 当前 API 没有卸载源触发器或删除捕获资源端点，因此没有显示虚假“停止并卸载”操作。暂停对象不会停止源端捕获。
