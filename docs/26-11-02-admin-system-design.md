# 2026-11-02 系统管理界面整理与检查记录

本轮整理用户与组织、角色与权限、审计日志、API密钥、模型与系统配置五个顶级页面，以及配置内的组织、模型、通知、安全区域。只调整界面布局及已有交互接线，没有更改账号、角色权限、密钥或模型数据库配置。以下实际检查由主会话通过官方CUA在2560×1440和1920×1080完成。

## 界面改动

- 账号资料限制最大宽1120，姓名/状态与五项资料分层，避免少量字段撑满整屏。
- 角色列表增加本地名称/编号搜索，左栏256；三个权限分组顶对齐，内置角色的已选禁用项提高对比，保持只读。成员与密钥列表复用既有adaptive分页，窗口测量后仍向后台发送真实page/size；未增加测量系统或假分页。
- 密钥与审计的搜索、筛选和操作归入同一工具条；合理分配列宽、长值截断/提示，表格独立滚动、页脚保留。密钥掩码、生成/轮换/吊销确认、权限及未保存保护保持；审计仍用正式游标分页，每页10条。
- 系统配置统一导航、分组标题、表单宽度与主次操作；模型用途导航、Ollama目录选择、组织/通知/安全布局沿用现有Ant组件与深海军蓝/浅色主题变量，不增加实现说明横幅、页签统计或装饰性框架。侧栏离开未保存页面的确认避免重复弹出。
