# 我的页面：手动取数、模板与共享

2026-10-27。本轮复用现有页面 JSON 和只读 SQL 网关，无数据库结构变更，不启用自动计划、订阅发送或新的模型调用。

## 执行来源

- 新的真实问数回答同时保存服务端 SQL、发布 ID/版本及 `sem_plan.execution.kind=guarded-sql-v1`。页面接口不接收 SQL 或执行计划入参。
- 向后兼容仅限非 seed、成功 `answer`、有服务端 `sql_text` 且 `release_id`、`answered_ver` 明确匹配当前发布的旧真实轮次。固定时重新校验并读取，不复制旧回答结果，不回写历史轮次；缺 SQL、失败、seed 或版本不明的记录不可追认为执行源。
- 只重放原 SQL，范围、时间和口径条件不做字符串替换。模板创建锁定原条件；不允许用新范围或口径标签冒充实际筛选。
- 原发布不再是当前发布、卡片口径待更新、缺执行定义、图形映射不明确时拒绝。本轮只支持有明确列结果的表格卡片。
- 按发布快照及既有 `snapshot_flags`/物理字段映射核对 SELECT、WHERE、GROUP、ORDER 等实际列引用。隐藏、敏感、未公开或无法证明的字段拒绝；`SELECT *` / `t.*` 拒绝，`COUNT(*)` 保留。不能确认的复杂列引用同样拒绝，不推断映射。

## 读取与权限

每次实际取数重新解析当前有效用户、本体成员和真实功能/行权限，不因为是页面拥有者复用旧权限。页面共享只决定能否打开；它不授予业务数据权限。部门共享要求部门精确一致。预览身份统一要求真实 `roles:manage`，写入仍受历史/预览只读限制。

卡片缓存指纹含实际用户、本体、编译后的行范围及功能权限。版本或指纹不合适时不返回旧值；共享详情 GET 可按当前查看人临时计算，仅返回本次投影，不修改拥有者缓存。无安全执行源时只返回卡片框架和准确不可用原因。列表不执行卡片查询、不返回缓存数据。

执行复用配置好的 QA 专用只读连接及 `run_guarded`，不回退主库连接；受控表注入本体及当前行范围。单页最多 20 张卡，整页共用现有 `qa_statement_timeout_ms` 总时限；在一个 REPEATABLE READ 只读事务里取数。单卡最多保存 200 行，额外取一行判断截断。只有全部成功才整体替换缓存及刷新时间；失败标记真实状态，保留旧缓存和原刷新时间，旧缓存是否可展示仍须再次经过身份、发布和公开列校验。

## 接口与页面

- `POST /api/qa/v1/pages`：空白页、已有模板，或 `sourceSessionId` 对应本人真实会话的可执行回答。成功后默认仅自己、手动刷新、订阅关闭。
- `POST /pages/{id}:refresh`：拥有者或当前可编辑成员手动刷新，返回实际页面状态。无编辑权限不能写缓存。
- `POST /pages/{id}:template`：拥有者保存可执行卡片结构与原条件，模板结果缓存为空；创建模板页时按创建者当前权限重新取数。
- `GET /pages/{id}/share-options`：拥有者访问当前本体有效成员候选，默认 10 条服务端分页；仅列有真实页面查看权限的人。共享保存用稳定用户编号、真实部门及 `lockVersion`，本体 viewer 不能获可编辑成员权限。
- `PUT /pages/{id}/share`：拥有者保存真实成员/部门共享；链接为当前站点 `/use/qa/pages?ontology=...&page_id=...`，不扩展原共享范围。
- `GET /pages/{id}/export`：重新检查当前页面可见性、共享导出开关及每个涉及对象的真实 `view/export` 授权；历史/预览拒绝。只导出当前权限可安全展示的有界结果，CSV 明示最多 200 行及是否截断，不称全量；单元格沿用公式转义。
- Workbench 的分享入口转为整理真实回答到页面，再设置共享；不再复制不可达的会话分享链接。历史会话固定每页 10 条后台分页；页面与模板列表也默认 10 条，页签无数量。
- 原有“每天/邮件若干人”等记录保留，真实界面显示自动刷新/订阅未启用，并可明确改成手动且关闭订阅。后端拒绝保存未实际运行的定时或订阅计划。

## 核查与边界

本轮执行了 6 个 QA Python 文件 AST 解析、新执行模块/页面接口 Ruff F/I，以及前端 `vue-tsc --noEmit`，均通过。未运行后台测试、pytest、集成/迁移测试、合成 HTTP、SQL 执行、模型调用、真实共享写入、页面/模板造数或业务写入。

实际浏览器核查由主任务进行，可进入 `/use/qa/workbench` 核固定 10 条会话、不可执行回答的分享状态；进入 `/use/qa/pages` 核旧页卡片框架、不可用原因、未启用计划、共享候选分页、取消草稿与模板按钮。只有数据库已有满足上述来源条件的真实记录时，才可核成功刷新与模板创建；本轮未查询数据库确认其存在，不以静态代码判断有可用来源，也未伪造来源。

尚未实测：成功重算、跨用户临时投影、刷新超时原结果保留、公开列及跨本体拒绝、共享写入/乐观锁并发、CSV 权限与截断、模板成功新建。自动刷新调度、外部订阅渠道、本轮未扩展的 Composer 对象引用继续未启用；新领域未绑定受控业务源时明确不可执行。ERP、Kafka、预测模型及模型提分评测按既定范围延后。
